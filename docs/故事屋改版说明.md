# 故事屋（故事界面）改版说明

改动目标：解决四个问题 —— **排版方向 / UI 质量 / 退出入口 / 内容切换**。
改动范围只落在故事屋模块（书架 + 阅读器）与其依赖的 3 个基础组件，**未触碰学习、复习、写字、设置等任何既有页面**。

| # | 文件 | 类型 | 说明 |

## 二、逐项对应你提的 4 个问题

### 1. 排版方向 → 横屏，且不溢出

- **锁横屏**：新增 `LandscapeScope`。进故事屋 → 锁定 `landscapeLeft/landscapeRight`；出故事屋 → 恢复 App 默认（竖屏 + 横屏全放开）。
  - 关键点：这个 Scope **只挂在书架（模块入口）**，阅读器不重复挂。否则从阅读器退回书架时，阅读器的 `dispose` 会把屏幕翻回竖屏，书架反而变竖屏。
  - 阅读器 `initState` 里只做一次幂等的 `LandscapeScope.enter()` 兜底，不在 `dispose` 里恢复。
- **收版心**：正文外面套 `Center > ConstrainedBox(maxWidth: 1100)`。横屏下一行字太长眼睛会「跳行」，两侧留白更舒服。
- **绝不溢出**：段落用 `LayoutBuilder` 拿真实可用宽度，左栏插图固定 `panelW = maxWidth * 0.30`（夹在 180~340 dp 之间），右栏注音正文走 `Expanded` + `Wrap`。
  → 文字宽度**永远是有界值**，不存在「宽度无限大导致溢出」的可能。
- **行距字距**：`RubyText` 新增两个参数，阅读器用 `runSpacing: 16`（行距）、`charSpacing: 4`（字距），注音和小字不再挤成一团。

### 2. UI 质量 → 重做视觉层次

- 配色/字号/圆角统一走 `AppTheme` + `AppDimens`，与「短句实战」「汉字学习」等页面同一套设计令牌：
  - 背景 `paper`（宣纸底）→ 段落卡片 `paper2` 45% 透明 → 分隔线 `line` → 主色 `dai`（黛青）。
  - 所有间距走 `gapS/gapM/gapL`，所有字号走 `d.fs()`（跟随平板缩放），触摸区 ≥ `d.touch`。
- 层次：
  - **书架**：封面缩略图（96×132）在左，书名/出处/难度星级/简介在右的宽扁卡片；`childAspectRatio: 2.75`，横屏 2 列。
  - **阅读器**：AppBar（返回 / 书名 / 目录 / 朗读本章）→ 章节头（「第 N / M 章」徽标 + 注音标题 + 分隔线）→ 段落卡片列表 → 底部翻章条。
  - 右下角主按钮「下一章」用 `daiSoft` 底 + `dai` 描边做主次区分；到最后一章变成「读完了 ✓」并置灰。

### 3. 退出入口 → 三层保险，随时出得去

| 层级 | 位置 | 行为 |
|------|------|------|
| AppBar 左上「‹ 返回」 | 书架 + 阅读器都有 | 图标 + 文字，热区 ≥ 64dp，老人好点 |
| **系统返回键 / 手势返回** | 阅读器 `PopScope(canPop: true)` | 直接退回书架 |
| 底部导航 `AppBottomNav` | 书架（此前缺失） | 与其它页面一致，可随时切到别的模块 |
| 目录面板底部「返回书架」 | 阅读器目录 | 全宽 `OutlinedButton`，一键出模块 |

- 书架的返回做了兜底：能 `pop` 就 `pop`，若已是根路由则 `pushReplacementNamed(AppRouter.home)` 回首页。

### 4. 内容切换 → 上下章 + 目录跳转

- **上下章**：底部 `_ChapterPager` 常驻「‹ 上一章 / 下一章 ›」，中间实时显示「第 N / M 章 + 本章标题」。
  - 翻章前先 `TtsService.instance.stop()`，避免上一章的朗读串到下一章。
  - 索引 `clamp(0, 长度-1)`，越界安全。
- **目录**：AppBar「目录」打开 `showModalBottomSheet`，列出全部章节（带序号，当前章标 `dai` 徽标 + ▶），点任意一章直接跳。
- 退出、翻章都先停 TTS，不会「人走了还在念」。

## 三、交互/状态逻辑

- `StoryReaderScreen` 由 `StatelessWidget` 改为 **`StatefulWidget`**，内部只维护一个状态：`int _index`（当前章节下标）。
- 数据流仍是单向：`widget.book`（不可变数据）→ `_chapter` getter → UI。没有引入任何新的状态管理依赖（遵守「零新增 pub 依赖」红线）。
- 朗读：`_readChapter()` 把「章节标题 + 各段正文」用 `rubyToPlain()` 剥掉拼音后拼成一段，交给 `TtsService.speak`。
  ⚠️ 铁律不变：**永远只把真实汉字传给 TTS，不能传拼音字母**。

## 五、构建侧的一个坑（记录）

`flutter clean` 会删掉 `.android/`（Flutter 用来放插件符号链接的临时目录）。
本机**未开 Windows 开发者模式、也不是管理员**，重建符号链接会报：

```
Building with plugins requires symlink support. Please enable Developer Mode
```

**绕过办法**：用 PowerShell 的**目录联接（junction）**代替符号链接 —— junction 不需要任何特权。

```powershell
New-Item -ItemType Junction `
  -Path  'D:\Progect-3\wanqing_shizi\.android\plugins\flutter_tts' `
  -Target 'D:\flutter_pub_cache\hosted\pub.dev\flutter_tts-4.2.5'
```

插件清单从项目根目录的 `.flutter-plugins-dependencies` 里读（android / windows / linux / macos / ios 各平台都要建）。
建好后再跑 `flutter build apk`，Flutter 检测到链接已存在就会跳过创建。

> 注：打包命令仍需在**关闭沙箱 + 后台**的条件下跑，否则会静默退出。

## 六、另一个坑（顺手修掉）：APK 里一张配图都没有

**现象**：构建成功、不报错，但 APK 里只有 `assets/images/stories/.gitkeep`，18 张漫画配图全没打进去，
阅读器里所有插图都退化成占位框。

**真因**：**Flutter 的 pubspec 目录资源声明不是递归的。**
`- assets/images/stories/` 只会收进**直接位于该目录下**的文件。配图放在 `havoc/`、`market/`、
`nezha/` 等子目录里，于是全被漏掉。

**修法**：`pubspec.yaml` 里为每个故事子目录各补一条声明：

```yaml
flutter:
  assets:
    - assets/strokes.json
    - assets/images/chars/
    - assets/images/stories/
    - assets/images/stories/havoc/
    - assets/images/stories/market/
    - assets/images/stories/nezha/
    - assets/images/stories/pony/
    - assets/images/stories/simaguang/
    - assets/images/stories/whitesnake/
```

改完重新构建，APK 从 18.9MB → **71.1MB**，18 张图全部就位。
**以后每新增一个故事目录，都要记得在 pubspec 里补一行。**

## 七、独立 UI 审查后追加的修正（v1.1 二次打磨）

请了一位 Flutter UI 审查员逐行走查（只读），发现 3 处必改 + 6 处建议，已全部落地，`flutter analyze` 0 error。

### 必改
1. **书架卡片溢出（v1.0 真 bug）**：原 `childAspectRatio: 2.75` 宽高比固定，标题折行时卡片内容会撑爆。
   → 改用 `SliverGridDelegateWithMaxCrossAxisExtent(maxCrossAxisExtent: d.fs(520), mainAxisExtent: d.fs(230))`：
   宽屏 2 列、窄屏自动 1 列，且**卡片高度永远是固定的 230dp**，内容再多也不溢出。封面高 `d.fs(132)→120`。
2. **系统返回后 TTS 还在念**：`PopScope(canPop: true)` 没有停朗读逻辑，按系统返回键退回书架时朗读继续。
   → `_StoryReaderScreenState` 加了 `dispose()`，统一在销毁（含系统返回、底部导航切走）时 `TtsService.instance.stop()`。
3. **注音拼音字号不随放大、还会压字**：原拼音写死 `d.fs(20)`、槽位 `d.fs(26)`。
   → 改为随汉字等比 `fs*0.42` / 槽位 `fs*0.62`；超长拼音（如 shuāng）用 `FittedBox(scaleDown)` 自动缩进，**不再压到下一个字**。

### 建议（均已顺手处理）
- AppBar 标题加 `maxLines:1 + ellipsis`；返回按钮 / 两个动作按钮热区提到 `d.touch`（64dp），达标。
- 段落插图布局从「固定 0.30 宽度」改为 `Expanded(flex:3)` + 文字 `Expanded(flex:7)`，极窄屏也不挤。
- 段落插图高 `240→160`（一屏能看到更多文字）；多图 `200→150`。
- 风格对齐其它页：圆角统一用 `AppDimens.radius`（16，不再缩放成 20.8）；中文按钮文字改回 `serif`（与 BigButton 一致）。
- 「朗读本章」做成**开始/停止切换**：朗读中按钮变「停止朗读」，妈妈不用退出或翻章就能停。
- 目录点当前章也有高亮反馈（原本就先 `pop` 再跳转，弹窗正常关闭）。
