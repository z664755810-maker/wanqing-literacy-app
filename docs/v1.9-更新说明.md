# 晚晴识字 v1.9 更新说明

> 本次解决两件事：**① 描红「左右能写、上下一写整屏就跟着滑」**；**② 朗读嗓音太生硬，且不想装第三方语音 App**。
> 第①个是 v1.7→v1.8 连修两次都没修干净的老问题，本轮抓到了真正的根因；第②个新增了「不装 App、挑本机自带中文嗓音」的方案。

---

## 一、描红：竖向不再滑屏 ✅

### 真因：田字格被包在了「会滚动」的容器里

描红在 App 里其实有**两条入口**：

| 入口 | 页面 | v1.8 时状态 |
|------|------|-------------|
| 单字页 → 去描红 | `trace_screen.dart` | ❌ 田字格被 `ListView` 包着 |
| 练一练 → 描红 | `practice_screen.dart` | ✅ 本来就不滚动 |

前两轮只改了第二条（本来就没问题），**漏了第一条**——而母亲常用的正是「看完一个字 → 去描红」这条路。

为什么在滚动容器里就会「上下滑屏」？Flutter 里一次拖动要在多个「手势识别器」间竞争：
- 田字格自己有 **Pan 识别器**（横竖都能画）；
- 外面的 `ListView` 还有个 **竖向拖拽识别器**（负责滚动页面）。

于是：
- **横向笔画** → 没人跟它抢 → Pan 赢 → 能正常写 ✅
- **竖向笔画** → `ListView` 的竖向识别器抢先获胜 → Pan 判负 → 页面滚起来 ❌

正好就是「左右没事、上下滑屏」。v1.8 加的 `HitTestBehavior.opaque` 解决了"田字格收不到手势"（所以横向能写了），但解决不了"纵向手势被别人抢走"——两件事得一起修。

### 本次怎么修的
1. **`trace_screen.dart` 去掉 `ListView`**，整屏改成不滚动的固定布局：顶部紧凑信息卡 + 中部田字格（`Expanded`）+ 底部「听读音 / 完成」。竖向手势再无竞争者。
2. **顺手修了布局溢出**：`practice_screen` 的 `_TraceBody` 预留高度原来拍魔法数字，超大字号下按钮被挤出屏；改成逐项累加真实开销，并把顶部示范字缩小（田字格内已有大号浅色范字）。四档字号均核算过，不溢出。

## 二、朗读嗓音：不装任何 App，挑本机自带中文嗓音 ✅

### 为什么不用文档里那招
上一版建议装「讯飞语音 / Google 文字转语音」换更自然的嗓音，但**装 App + 下载语音包 + 切引擎**对您和母亲成本太高、太折腾。

### 性价比高的做法（本次新增）
**不装任何软件**，直接在 App 里挑平板**自带**的中文嗓音：
1. 设置页新增「**朗读嗓音**」一栏，列出本机已安装的**中文**嗓音（荣耀 / 华为平板自带的中文 TTS 引擎通常就够自然）。
2. 点一下某个嗓音，**立刻试听**一句「你好，我是晚晴识字，我们一起慢慢学。」——当场对比哪个顺耳。
3. 选中即生效、自动记住，下次打开直接用。默认仍是「自动（系统推荐）」。

### 如果本机一个好听的都没有（仍零成本）
只需在**系统设置**里开启免费的中文语音数据，无需安装软件：
- 荣耀 / 华为：`设置 → 辅助功能 / 智慧助手 → 文字转语音输出（TTS）→ 首选引擎` → 选设备自带的中文引擎，并「下载 / 安装中文（普通话）语音数据」。
- 系统自带、免费，和 App 无关；开好后回 App 设置页「朗读嗓音」里就能看到并挑选。

这样既**不破「零新增依赖」红线**，又让朗读明显更自然，代价只有一个免费的系统开关。

## 五、教训（已固化进 memory）
1. **绘图 / 手写 / 签名类组件，绝不能放进 `ListView`、`SingleChildScrollView`**——滚动容器会在手势竞技场抢走纵向手势，表现恰是「横向正常、竖向异常」。此指纹一出现先查滚动祖先。
2. **`HitTestBehavior.opaque` 只保证"收得到手势"，不保证"收得到纵向手势"**——两件事要分清。
3. **固定屏布局的预留高度禁止拍魔法数字**，要逐项累加真实开销，并在各字号档位手算核验。
4. **同一功能有多个入口时，改 bug 必须先 grep 出全部调用点**——描红有两条路，只改一条就留下"修了一半"的假象（v1.7→v1.8→v1.9 连翻三次栽在这）。
