# 晚晴识字 · 成人汉字/拼音学习平板应用 — 方案（定稿 v3）

> 目标用户：用户母亲，约 50 岁，未受义务教育，仅识少量基础汉字，学过拼音但自觉"学不明白"。
> 设备：荣耀平板（Android / MagicOS）。语气与视觉：稳重、有课堂感，**坚决去儿童化**。
> 应用名（暂定）：**晚晴识字**（"人间重晚晴"，书卷气、尊重晚学）。

---

## 1. 产品原则（不可妥协）
1. **尊严优先**：不用"宝宝""小朋友"等儿童称呼与语气；不说教、不哄。措辞如"一位沉稳的语文老师"。
2. **生活即教材**：拼音、汉字都落在买菜、节气、节日、老家、信仰等她熟悉的生活场景里。
3. **逻辑而非无厘头**：系统课程按"主题/场景/笔画由少到多"进阶；不随机蹦字。
4. **主动 + 被动结合**：既能按系统进度学，也能凭兴趣进文化分类自由学。
5. **温故知新**：复习不是"过了就完"，认识也要按间隔持续回炉。

---

## 2. 用户画像与痛点
- 痛点 A：拼音"学不明白"→ 需要**慢速、清晰、可反复跟读**的真人感发音 + 声母→韵母→声调的顺序。
- 痛点 B：识字零散→ 需要**成组、有语境**的字（数字/身体/自然/家庭/方向）。
- 痛点 C：记不牢→ **间隔重复 + 定时提醒 + 手写巩固**。
- 兴趣点（用于主动学习分类）：烧香信神仙、老家河南、二十四节气、传统节日。

---

## 3. 功能规划（四大模块）
### 3.1 拼音课堂（含「拼音小课堂」）
**新增 · 拼音小课堂（入口第一屏）**：先讲清"为什么要学拼音"，再进入分项，避免"一脸懵"。
- 一、拼音是什么：给汉字标"怎么读"的字母，如 妈 → mā。
- 二、为什么值得学：查字典 / 手机打字 / 自己读生词 / 拼音是汉字的声音（烧香念的"南无阿弥陀佛"每字也有拼音，学会了自己能读经）。
- 三、怎么拼成字音：声母 + 韵母 + 声调 = 一个字；**特别说明 zh/ch/sh 是整体音，不是 z+h 两个字母**（这是上一版被系统 TTS 读错的根因）。
- 四、声调决定意思：妈/麻/马/骂 同音不同调，意思全变 → 声调必须一起学。

**三个可切换分区**：**声母（23）/ 韵母（24）/ 声调（4+轻声）**，点击即时切换。
- 每个音：大字 + ▶听读音 + 例字例词；声调显示调号与"高平/升/拐弯/降/轻短"说明。
- **发音正确性修复**：声母/韵母点击播放的是"真实音节示例"（如 zh → 知 zhī），不再是按英文字母拼读。正式版将**内置录音级发音音频**，声母本音也自然；当前原型用浏览器 TTS 演示此逻辑。
- 学习顺序提示：先声母 → 韵母 → 拼读 → 声调。
- 拼音总表经逐条人工校验（声母 23、韵母 24、声调 5），例字与拼音一一对应、无错音。

### 3.2 汉字课堂（本次重点重构）
**顶部两段式切换**：
- **系统课程（逻辑进阶）**：数字与时间 / 人称与身体 / 自然万物 / 家庭亲朋 / 方向处所。每字含：大字、拼音、笔顺动画（田字格逐笔）、释义、例词例句、跟读。
- **文化分类 · 主动学习**（你母亲的兴趣入口）：
  - 二十四节气：春 夏 秋 冬 立 分 至 雨 雪 霜 露 寒 暖
  - 传统节日：节 春 元 宵 端 午 重 阳 腊 八 除 夕 灯 龙 舟
  - 神仙民俗：佛 神 仙 财 福 禄 寿 喜 灶 香 庙 经 善 拜 观 音 菩 萨 道 德 平 安 吉 祥（紧扣"信神佛、爱烧香"）
  - 老家河南：河 南 黄 嵩 洛 阳 豫 州 中 原 华 夏 商 都（紧扣"河南、黄河、中原"）
  - 厨房饮食（生活经验入口）：米 面 盐 油 茶 饭 菜 肉 汤 锅 碗 筷 勺
- 每个分类点开是一组字卡，点字进详情；详情含**笔顺动画（田字格逐笔）+ 释义 + 例词例句 + 跟读 + ☆收藏**；详情可"返回字表"继续翻。

### 3.3 每日阅读
- 短文卡片（首版 8 篇，按画像扩充）：
  - 神仙民俗：《烧一炷香》《南无阿弥陀佛》《好心的财神》
  - 二十四节气：《立春·种下希望》
  - 传统节日：《过年回家》
  - 老家河南：《河南老家》
  - 厨房/生活：《厨房里的学问》《身体的信号》
- **已学字高亮**（蓝色标记，点蓝字可查读音释义），整篇朗读 + 分段跟读。
- 内容可预置，后续儿子可在文件中补充（题材已覆盖其信仰、老家、生活经验）。

### 3.4 复习巩固（本次重点重构）
- **听音辨字（市面语言工具常见练耳法）**：播放音节 → 四选一选正确字，即时反馈，强化"音→形"对应。
- **手写温习**：卡片跟读 → 三档自测 **认识 / 模糊 / 不认识**。
- 点「认识」→ 弹出**田字格手写一遍**提示（原型支持手指书写）。
  - 写错 → 标记「仍需复习」，稍后再次出现。
  - 写对 → 「温故知新」提示：已掌握也要常回头，之后仍安排复习（不一劳永逸）。
- 模糊/不认识 → 尽快重排。
- 间隔重复引擎：Leitner 盒 或 SM-2（见 §6）。

### 3.5 借鉴市面语言学习工具的能力（已纳入规划）
- **连续打卡 / 学习统计**：首页显示"今日已学 N 字 · 连续 M 天"，用温和的正反馈替代排行榜。
- **收藏本（生词本）**：任意字详情可☆收藏，集中复习。
- **听音辨字测验**：见 3.4。
- **笔顺动画描红**：见 3.2，用 hanzi-writer 类库实现逐笔（正式版内置本地笔顺数据，离线可用）。
- **跟读评测（进阶）**：后续可接离线语音识别做跟读打分（首版仅提供示范音+手写巩固）。

## 4. 内容体系（首版范围）
- 汉字：约 150–200 个生活高频字，按上述主题分组 + 文化分类覆盖（原型已落地 ~120 字，含神仙民俗/河南/厨房饮食全套）。
- 拼音：声母/韵母/声调全集，逐条校验，每个配正确例字例词。
- 阅读：8–12 篇短文（神仙民俗 + 节气 + 节日 + 河南 + 厨房/生活），已学字标注。
- 数据形式：内置 JSON/资源文件，便于儿子后续增删。

## 5. 技术架构与选型（已确认）
- **技术栈：Flutter（Dart）**——你已有 Flutter 经验，迭代快，单代码库出 Android。
- **语音（TTS）**：首版用**系统 TTS（Android TextToSpeech，zh-CN）**兜底；后续可换**讯飞/火山引擎成人播音员音**（更自然稳重，需联网/可能付费）。
- **本地存储**：SQLite（drift 或 sqflite）——进度、复习排程、用户补充内容全本地，**隐私、可离线**。
- **通知**：flutter_local_notifications 做定时复习提醒。
- **笔顺动画**：hanzi-writer（逐笔描红，社区成熟方案）；正式版将笔顺数据内置本地（离线可用），不依赖 CDN。
- **横竖屏**：支持切换，**默认横屏**（平板阅读更自然）；用 `OrientationBuilder` 响应式布局。
- **无后端**：单机应用，母亲的数据不出平板。

### Flutter 工程结构（示意）
```
lib/
  main.dart
  theme/            # 宣纸/墨/黛青/赭石 主题，宋体大字
  models/           # 字、拼音、故事、复习记录
  data/             # 内置字库/拼音/故事的 json + 笔顺资源
  db/               # drift 本地库
  tts/              # 朗读封装（系统TTS，预留播音员音接口）
  screens/          # home / pinyin / hanzi / read / review
  widgets/          # 字卡、田字格、复习卡、底部导航
  notify/           # 定时提醒
```

## 6. 复习与提醒机制
- 每个字维护熟练度等级（Leitner 1–5 盒）。
- 认识且手写对 → 升盒、拉长间隔（如 1/3/7/15/30 天），仍会回炉。
- 模糊/不认识/写错 → 降盒、次日或当日再现。
- 每日固定时段推送"今日待复习 N 个"通知（时间可在设置里调，建议上午或晚饭后）。

## 7. UI 设计语言（原型已落地）
- 底色：宣纸米 `#F3ECDD`；卡片 `#FBF6EA`。
- 文字：墨黑 `#2B2B2B`；正文用无衬线，汉字/标题用宋体（思源宋体优先，回退 Songti/STSong）。
- 强调色：黛青 `#2F5D57`（主操作/已学）、赭石 `#9C5B3B`（次操作/分类）、金 `#B7902F`（标签）。
- 无卡通吉祥物、无星星贴纸、无排行榜；大触控区、大字号（正文 ≥18px，字 ≥30px）。
- 原型文件：`prototype-晚晴识字.html`（可在浏览器/平板浏览器体验，朗读用浏览器中文 TTS）。
