# 晚晴识字 v1.8 更新说明

> 面向母亲（约 50 岁、河南农村、识字有限但有拼音基础）的纯离线识字 App。
> 本次更新专门修复 v1.7 实机体验后仍存在的三个问题：**设置点了没反应、朗读太快且生硬、描红一写整屏跟着滑**。

## 一、本次改了什么（用大白话讲）

### 1. 设置现在「一点就变」✅
之前在设置页改了「字号变大 / 语速变慢 / 按钮变大」，要退出重进才生效，有时干脆没反应。
根因是 App 用了「最外层监听」的方式，但翻到设置页这种「分页」（走导航栈）并不会跟着刷新。

修法：把全局设置改成「通知作用域」机制——**只要改了设置，屏幕上所有页面立刻跟着变**，不用退出、不用重启。
现在在设置页把字调到「超大」、语速调到「很慢」，页面当场就变大、变慢，手指直接能感受到。

### 2. 朗读更慢、更自然 ✅
之前每个字念得太快，"还没听清就结束了"，而且发音干巴巴不好听。

两处根因都修好了：
- 中文嗓音**以前根本没被选上**（代码里一个括号写错，把"等结果"当"结果列表"处理，直接报错被吞掉），一直用系统默认生硬嗓音。
  现在正确挑中 **中文（普通话）嗓音**，念字更顺耳。
- 默认语速从「慢速(0.3)」降到「**很慢(0.2)**」。如果您之前从没手动调过语速，装上新包会自动变成最慢档；手动调过则保留您的选择。
- 设置页语速档位：**很慢 / 慢速 / 稍快** 三档，母亲日常用「很慢」最合适。

### 3. 描红能一笔一笔画，屏幕不再乱滑 ✅
之前手指在描红格子里一写，整个屏幕跟着手指上下滑动，根本写不稳。

根因：手写格子"没接住"手势，竖笔被外层页面抢走去滚动了。
修法：让手写格子**独占格内全部手势**，手指只在格子里留下笔画，外层页面纹丝不动。现在可以断笔、多笔、慢慢描，像在纸上写一样。

## 三、朗读嗓音想更好听？（可选，进阶）

v1.8 已自动选系统里的**中文普通话**嗓音。若母亲觉得还不够自然，可在平板上安装更自然的**中文语音包**：

- **讯飞语音 / 科大讯飞语音引擎**（应用商店搜"讯飞语音"）：中文朗读最自然，强烈推荐。
- **Google 文字转语音引擎** + 下载「中文（普通话）」语音数据：系统级，App 会自动识别并选用。

安装后重开本 App 一次，朗读即切换为更自然的嗓音（App 启动时会重新挑中文嗓音）。

## 四、技术改动摘要（给开发者）

| 文件 | 改动 |
|------|------|
| `lib/theme/app_dimens.dart` | 改造为 `InheritedNotifier<AppState>` 作用域 `AppDimensScope`；`of()` 注册依赖，路由页随 notify 重建 |
| `lib/main.dart` | 去掉 `ListenableBuilder`，改用 `AppDimensScope` 包 `MaterialApp` |
| `lib/services/tts_service.dart` | 修正 `getVoices`（getter，非方法）调用，挑 zh-CN 嗓音；`setVoice` 用中文名优先 |
| `lib/state/app_state.dart` | 默认语速 0.3 → 0.2；`fromJson` 旧默认 0.3 自动迁移到 0.2 |
| `lib/screens/settings_screen.dart` | 语速档位 `[0.2, 0.3, 0.4]`（很慢/慢速/稍快） |
| `lib/widgets/handwriting_pad.dart` | `GestureDetector` 加 `behavior: HitTestBehavior.opaque` 独占手势 |
| `pubspec.yaml` | `version: 1.8.0+12` |

构建：`flutter build apk --release --split-per-abi --target-platform android-arm64`
交付：`dist/晚晴识字-v1.8-arm64.apk`（246,873,056 B，已签名，arm64 单包，apksigner verify 通过 CN=Wanqing Shizi）。

## 五、三条跨项目教训（已固化进 memory）

1. `ListenableBuilder(MaterialApp)` 无法让导航栈里的路由页重建——全局设置/状态要即时作用所有页面，必须用 `InheritedNotifier`/`InheritedModel` 作用域让 `of` 注册依赖。
2. flutter_tts `getVoices` 是 **getter**，`await _tts.getVoices as X` 会把 Future 当 X 转（运算符优先级坑），务必 `(await _tts.getVoices) as X`。
3. `GestureDetector`+`CustomPaint` 必须 `behavior: HitTestBehavior.opaque`，否则手势穿透到外层滚动/滑动。
